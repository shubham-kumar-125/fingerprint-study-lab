Reproducible from the start

A research path built to expose weaknesses.

The reference project compares LeNet, AlexNet, VGG16, and ResNet across eight label folders. This version starts with a reproducible ResNet-18 baseline and adds the checks that determine whether an apparent result is worth investigating.

01 · GOVERN DATA

Consent & provenance

Keep biometrics local. Record source, permission, labels, acquisition conditions, and a deletion/retention plan.

02 · PREVENT LEAKAGE

Split by person

Images from the same participant never cross train, validation, and test splits. Image-level random splits can exaggerate performance.

03 · EVALUATE HONESTLY

Report uncertainty

Inspect macro-F1, per-class error, confidence, calibration, and an external dataset—not only one accuracy number.

Local project

What the code does

  • Reads a manifest with image path, label, and participant ID.
  • Trains a PyTorch ResNet-18 baseline from scratch.
  • Saves a model checkpoint, split counts, macro-F1, confusion matrix, and confidence summary.
  • Prints a permanent research-only warning for local experimental scores.
Why the demo does not accept uploads

Your fingerprint is biometric data.

This public site intentionally does not collect images. Uploading real fingerprints to a public demo creates privacy risk and could encourage unsafe medical interpretation. Use the local pipeline only with an approved research dataset.
